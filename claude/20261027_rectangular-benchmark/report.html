4×2 and 4×4 benchmark

Global negamax versus local-only Fairy-Stockfish, with matching local-only controls. Four columns in both layouts: eight boards on 4×2, sixteen on 4×4.

1,200 / 1,200 scored games complete.

On 4×4, Casual global scored 83.0% (63.3%–90.9%, 95% bounds) against Strong local; its local-only control scored 4.0%. 3 of 3 global presets have a score lower bound above 50% on 4×4, versus 0 of 3 on 4×2.

Casual global completed no search depth on 95.2% of its 4×4 moves. In that case it returns the capture-priority fallback, with king captures ranked highest. These results do not isolate the benefit of negamax. The next useful control is that fallback without search.

Method

Each condition has 100 games, split evenly by color. A win earns one point, a draw half a point. Win rate and match score have conservative 95% bounds based on color-swapped pairs.

The current bots use the same presets as the 2×2 study. Global search keeps all legal moves, with a 100,000-node cap. Games end under the actual rules, without evaluation adjudication or a move-limit draw.

Each condition first gets ten unscored determinism pilots. Forced two-ply openings are used only if all five traces repeat within each color. 0 of 12 completed pilot conditions required forced openings.

24 parallel games. System CPU: 85.6% mean, 99.2% peak. Peak summed benchmark RSS: 15.5 GiB; peak system memory use: 34.1%. Summed RSS includes shared pages.

Intervals describe these runs under shared machine load. They are per condition, assume independent color pairs, and do not establish optimal play or calibrated Elo.
