Method

Six conditions, 100 scored games each, 50 per color. Win rate counts wins only; match score counts a win as 1 and a draw as ½. Conservative 95% bounds use the same color-paired Bonferroni–Clopper–Pearson method as earlier studies, per condition, assuming independent pairs. They do not cover the whole matrix simultaneously.

The ten-candidate implementation is unchanged from the feature branch: alpha-beta, iterative deepening, ranked candidate ordering, routing/king-capture additions, caching, capture-priority fallback and the existing heuristic match-score aggregation. Casual: depth 2 / 600 ms; Strong: depth 4 / 1,600 ms; Maximum: depth 6 / 4,000 ms. All have a 100,000-node cap and keep only the last completed iteration.

Scalar analysis uses 64/128/256 Fairy-Stockfish nodes for Casual/Strong/Maximum. Candidate requests use ten times those budgets. Candidate calls are included in total engine calls; their cost is greater than a scalar request. These are the existing unequal preset budgets, rather than an equal-compute efficiency comparison.

Depth zero returns the capture-priority fallback without completing a search iteration. A high match score with frequent fallback use does not isolate a benefit from MultiPV or global planning.

Local Strong uses skill 10 / 300 ms; local Maximum uses skill 20 / 900 ms. Free-board selection is legal_boards[global_ply % legal_boards.len()]. Release build, 24 parallel games; Fairy-Stockfish 1.1.12, one thread, NNUE off.

Sixty unscored determinism pilots: five games per color per condition. 0 of six conditions required forced two-ply classical openings. Games finish under actual rules, without evaluation adjudication or a move-limit draw.

The earlier full-width, fallback, material and local controls ran separately. Host load and stochastic engine play can affect time-budgeted strength. Point differences do not isolate a causal improvement. The match-score heuristic is uncalibrated; the observed results establish neither optimal play nor Elo.
